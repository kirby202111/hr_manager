电子车间安全规范

一、车间出入管理
1. 所有进入车间人员必须穿戴防静电工作服、防静电鞋和防静电手环
2. 禁止穿拖鞋、凉鞋、高跟鞋进入生产区域
3. 长发必须束紧并收入工作帽内，禁止佩戴悬垂饰物
4. 外来访客须由专人陪同，佩戴临时访客证并穿戴防静电装备

二、电气安全
1. 所有电气设备使用前检查电源线是否破损，插头是否松动
2. 禁止私拉乱接电源，临时用电需经工程部审批
3. 设备维修和保养必须执行停电挂牌制度（Lockout/Tagout）
4. 工位最大工作电压：测试工位不超过250V AC，普通工位不超过36V DC
5. 发现电气异常（异响、异味、冒烟）立即断电并报告工程部

三、化学品管理
1. 车间常用化学品包括：助焊剂、异丙醇（IPA）、焊锡膏、清洗剂
2. 所有化学品必须存放在指定柜内，贴有MSDS标签
3. 使用化学品时佩戴防护手套和护目镜
4. 异丙醇等易燃品使用量不得超过当日用量，剩余部分及时归还仓库存放
5. 化学品溅入眼睛立即用洗眼器冲洗15分钟并就医

四、防静电（ESD）管理
1. 所有工位必须使用防静电台垫并可靠接地，接地电阻小于1兆欧
2. 每班次开始前用万用表检测防静电手环接地是否良好
3. 元器件和PCB板必须存放在防静电包装内，使用防静电周转车转运
4. 非防静电物品（塑料袋、泡沫等）禁止放置在防静电工作台上

五、消防安全
1. 车间配备ABC干粉灭火器和CO2灭火器，每50平方米至少配置2具
2. 灭火器位置标识清晰，前方1米内不得堆放物品
3. 消防通道和安全出口时刻保持畅通，禁止堆放任何物品
4. 每半年组织一次消防演练，新员工入职一周内必须参加安全培训

六、应急处理
1. 急救箱位置：车间入口左侧、品质部办公区、仓库门口各一个
2. 紧急联系电话：安全主管139XXXX1234、厂区医务室分机8801
3. 发生人员受伤：立即进行急救，拨打120并通知安全主管
4. 发生火灾：立即按响火警，使用灭火器初期扑救，无法控制时迅速撤离

七、设备操作授权
1. 所有生产设备实行授权使用制度，未经培训考核不得操作
2. 设备操作权限分三级：初级（基本操作）、中级（参数调整）、高级（维修保养）
3. 未经授权更改设备参数视同违章操作

八、事故报告
1. 任何安全事故（包括未遂事故）必须在24小时内填写事故报告
2. 事故报告提交至安全主管，重大事故同时报告工厂管理层
3. 严禁隐瞒事故或迟报事故
