电子车间设备使用指南

一、示波器操作
1. 开机前确认电源电压为220V AC，检查探头补偿是否正常
2. 通道设置：按下CH1/CH2按钮选择通道，旋转VOLTS/DIV调节垂直灵敏度
3. 时基设置：旋转TIME/DIV调节水平扫描速度，根据信号频率选择合适档位
4. 触发设置：选择触发源（CH1/CH2/EXT），调节触发电平使波形稳定
5. 测量功能：按Measure键可自动测量频率、幅值、上升时间等参数
6. 注意事项：测量高压时使用10:1衰减探头，接地夹必须接电路地端

二、数字万用表操作
1. 测量电压：将旋钮转至V档位，红表笔插V/Ω孔，黑表笔插COM孔
2. 测量电流：将旋钮转至A档位，红表笔插mA或10A孔（注意量程）
3. 测量电阻：断电后测量，将旋钮转至Ω档位，表笔跨接被测元件两端
4. 通断测试：旋钮转至蜂鸣档，表笔接触被测点，导通时蜂鸣器响
5. 注意事项：测量前确认量程选择正确，禁止在带电状态下测量电阻

三、热风枪操作
1. 根据元件类型选择温度和风量：IC芯片温度320-380°C、风量3-4档
2. 风枪嘴距PCB板1-2厘米，均匀加热焊点区域
3. 观察焊锡融化后用镊子取下元件，不可强行撬起
4. 加热时间不宜过长，单点加热不超过30秒，防止烫伤PCB板
5. 使用完毕将温度调至最低，冷却2分钟后再关机

四、直流稳压电源
1. 开机前将电压和电流旋钮调至最小
2. 连接负载后再逐步调高电压至所需值
3. 电流限幅设定：根据被测电路最大电流设定保护值，防止过流损坏
4. 双路电源串联使用时注意正负极连接方式
5. 关机时先调回零位，再断开负载

五、信号发生器
1. 选择波形类型：正弦波、方波、三角波等
2. 设置频率和幅值，确认输出阻抗为50欧姆或高阻
3. 先设定参数再开启输出，避免输出不确定信号
4. 使用BNC同轴电缆连接，确保接触良好

六、回流焊炉操作
1. 温度曲线设置根据焊锡膏规格书确定，典型无铅曲线：预热150-180°C、回流峰值240-250°C
2. 每班次首板必须通过温度曲线测试仪验证曲线合格
3. KIC温度曲线测试仪使用：将热电偶固定在PCB关键位置，随板通过回流炉记录温度
4. 曲线超标时停止生产，通知工程部调整参数

七、设备校准与维护
1. 示波器和万用表每年校准一次，校准标签贴在设备醒目位置
2. 热风枪温度每季度用温度计校验一次
3. 回流炉每半年由供应商进行校准和维护
4. 设备点检表每日填写，异常情况及时报修
